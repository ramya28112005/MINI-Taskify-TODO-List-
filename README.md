

# ✨ Taskify – Smart Todo List

A simple, stylish, and responsive Todo List web application built using HTML, CSS, JavaScript, and Bootstrap. Taskify helps users organize daily tasks, track their progress, and manage their productivity.

## 🚀 Features

- **Add Tasks:** Create new tasks easily.
- **Complete Tasks:** Mark tasks as completed or pending.
- **Delete Tasks:** Remove tasks you no longer need.
- **Task Statistics:** View total, pending, and completed tasks.
- **Progress Tracking:** Monitor your task completion percentage with a progress bar.
- **Task Filters:** Filter tasks by All, Pending, or Completed.
- **Date Display:** View the current date.
- **Local Storage:** Automatically save tasks in the browser so they remain available after refreshing the page.
- **Responsive Design:** Works on desktop, tablet, and mobile screens.
- **Modern UI:** Enjoy a clean layout with a gradient background, purple accents, and interactive elements.

## 🛠️ Technologies Used

- CSS3

## 💻 How to Run the Project

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Start adding and managing your tasks.

No additional installation is required.

## 📸 How to Use

1. Enter a task in the input box.
2. Click **Add Task** or press Enter.
3. Click the checkbox or task text to mark a task as completed or pending.
4. Use the **All**, **Pending**, and **Completed** filters to organize your tasks.
5. Click **Delete** to remove a task.
6. Monitor your progress using the dashboard statistics and progress bar.

## 💾 Data Storage

Taskify uses the browser's Local Storage to save task information. Your tasks remain available after refreshing the page in the same browser, provided the website's stored data is not cleared.

## 🎯 Project Objective

The objective of this project is to practise JavaScript fundamentals, DOM manipulation, event handling, array methods, functions, and browser Local Storage while building a useful productivity application.
